A Python program — standard library only, no network — that writes one text to /output/entry.txt: a monologue of exactly 100 words (526 characters, inside the competition's gate of 1 to 600 characters of UTF-8 text) spoken by a fantasy villain who is secretly just very tired. The tiredness lives in the voice — tea, leaning candles, a heavy cloak, a prophecy postponed until he has sat down — while his doom engine still wakes at dawn. The file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
